# 📄 Research Paper Summarizer

A lightweight web app that takes a research paper (PDF) and generates a clean, readable AI-powered summary — no sign-up, no clutter, just upload and get the key points.

## 📖 Overview

Built as a learning project combining **web development** and **AI integration**: extracting text from PDFs, chunking long documents, and using an LLM to generate abstractive summaries — turning a dense research paper into a digestible summary in seconds.

---

## 🔍 How It Works

```
User uploads PDF
      ↓
Flask extracts raw text from the PDF
      ↓
Text is chunked (if too long for one AI call)
      ↓
Each chunk sent to AI model → summarized
      ↓
Summaries combined into one final summary (map-reduce)
      ↓
Result displayed on the same page — nothing saved
```

## 🚀 Getting Started

### Prerequisites
- Python 3.9+
- pip

### Installation

```bash
git clone https://github.com/your-username/research-paper-summarizer.git
cd research-paper-summarizer
pip install -r requirements.txt
```

### Configure environment variables

Create a `.env` file in the project root:

```
API_KEY=your_llm_api_key_here
```

### Run locally

```bash
python app.py
```

Then open **http://localhost:5000** in your browser.
